## 🐛 Bug Details

### Location
- **File**: `src/booking_system.py`
- **Method**: `MeetingRoomBookingSystem._validate_equipment_requirements()`
- **Line**: 112

### The Problem
The system approved booking requests when rooms had **SOME** required equipment instead of requiring **ALL** equipment to be present.

### The Solution
Changed the validation logic from checking ANY overlap to checking ALL requirements using Python's `issubset()` method.

### Code Change
```python
# BEFORE (Wrong)
has_any_equipment = bool(required_equipment & room.equipment)

# AFTER (Correct)
all_equipment_available = required_equipment.issubset(room.equipment)
```
